Drop your real image files in here. Nothing breaks if they're missing —
every spot has a text fallback — but the site looks much better with them.

  images/logo.png
    The band logo / avatar used in the header, browser tab icon, and
    home-screen icon on phones. Square works best (it's shown as a circle).
    Until you add one, a plain "LP" badge is shown instead.

  images/about/*.jpg (or wherever you point about-writer.html's image blocks)
    Any band photo you want inside the About page bio. Add an "Image"
    block in about-writer.html and point it at the file you drop here.

  images/music/*.jpg
    Optional single cover art. Only used on the Music page when a single
    doesn't have a YouTube video yet (music-writer.html's "cover image"
    field) — once a video is added, the video takes over that spot.

You do NOT need to add photos for the "Latest posts" section on the home
page — those are real, live Instagram embeds pulled straight from the
post links you add in posts-writer.html.
